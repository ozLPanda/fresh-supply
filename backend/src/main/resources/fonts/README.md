# Шрифты PDF

DejaVu Sans 2.37 (обычный и жирный) включены в backend JAR. Накладные, счета,
складские документы и названия товаров на штрихкодах используют эти шрифты
без зависимости от установленных в Windows, macOS или Linux шрифтов.

Источник: [официальный релиз DejaVu 2.37](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37),
архив `dejavu-fonts-ttf-2.37.zip`. Файлы не изменены.
Условия распространения находятся в `DejaVu-LICENSE.txt` рядом со шрифтами.
