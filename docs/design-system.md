# Визуальная система Ovoshi Help

Основа оформления взята из `hackalem-ai-base/frontend/src/shared/styles/tokens.css`,
`app/AppLayout.module.css` и `shared/ui`. Продукт и его контракты остаются магазином
«Фирма Актив». Текущий исходный Hackalem использует белую плавающую боковую панель;
старое описание панели без фона в его документации здесь не применяется.

## Тема

- Холст `#f7f6f4`, карточки `#fff`, утопленные поля `#f2f1ef`.
- Текст `#14151a`, вторичный `#6b6f76`, акцент `#1b84ff`.
- Для белого текста кнопок используется более тёмный `#0b5fc4`.
- Системный стек SF / Segoe / system-ui; заголовок страницы 26px/600.
- Карточки 16px, поля и кнопки 10px, небольшие элементы 8px, бейджи 20px.
- Тени `--sh-1`, `--sh-side`; разделители `--hair`.
- Боковая панель 236px, внешний отступ 16px. Сохранён breakpoint магазина
  1024px и его мобильное меню с жестом перетаскивания.

Единственный источник значений: `frontend/src/shared/styles/tokens.css`.
`frontend/src/styles.css` связывает существующие имена `--surface`, `--line`,
`--text`, `--orange` с новой темой. `--orange` является совместимым именем
основного акцента, теперь синего; семантические предупреждения остаются янтарными.
Цветовые ряды графиков остаются различимыми.

## Компоненты и поведение

Используйте существующие `AppButton`, `AppField`, `AppCard`, `AppDataTable`,
`AppBadge`, `AppModal`, `MetricCard` и остальные компоненты из `shared/ui`.
Стили находятся рядом с компонентами. Каталог: `frontend/COMPONENTS.md`.
API компонентов, формы, поиск, фильтры, сортировки, права доступа и обработчики
сохранены. Карточки/кнопки учитывают reduced motion; фокус остаётся видимым.

Витрина сохраняет каталог отопления и сантехники, изображения товаров и логотип
магазина. Главная, каталог, корзина, клиентские страницы и админка используют
одни поверхности, шрифты и акцент. Модули пополнения запасов, карты и ассистенты
Hackalem не импортируются в бизнес-логику магазина.

Не возвращайте устаревшие общие `.product-card`/`.store-shell` правила в
`styles.css`: они перекрывают локальный адаптивный дизайн витрины. Общий сброс
не должен задавать оформление любому `footer` или `table` на странице.
