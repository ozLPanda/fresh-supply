# WhatsApp: контакты и входящие сообщения

Раздел `/admin/whatsapp` показывает контакты и сообщения, полученные нашим сервером через
WhatsApp Cloud API. Meta присылает события на webhook; Cloud API не предоставляет загрузку
старой переписки или всей адресной книги по запросу. Поэтому список начнёт заполняться
после подключения webhook и первого входящего сообщения. Сейчас раздел доступен только
для чтения: отправка сообщений и автоответчик не включены.

## Настройка Meta

1. Создайте или выберите Meta Business Portfolio, WhatsApp Business Account (WABA) и
   бизнес-номер в Meta for Developers. Для разработки можно использовать тестовый номер.
2. В секретном окружении backend задайте `APP_WHATSAPP_PHONE_NUMBER_ID`,
   `APP_WHATSAPP_VERIFY_TOKEN` (создайте случайное значение) и
   `APP_WHATSAPP_APP_SECRET` (секрет приложения Meta). Не добавляйте значения в Git.
3. В настройках webhook Meta укажите публичный HTTPS URL
   `https://<домен>/api/whatsapp/webhook` и тот же verify token. Подпишитесь на поле
   `messages` для нужного WABA. Для подписки приложения на WABA может понадобиться
   `APP_WHATSAPP_WABA_ID`.
4. `APP_WHATSAPP_ACCESS_TOKEN` зарезервирован для исходящих вызовов Cloud API
   (например, будущего автоответчика). В текущем режиме приёма сообщений он не
   используется. Для production нужен токен системного пользователя с разрешением
   `whatsapp_business_messaging`; токен не должен попадать в браузер.
5. Откройте раздел админки с правами `pages.whatsapp.view` и `whatsapp.read`.
   Индикатор «интеграция настроена» означает, что обязательные переменные заданы,
   но не подтверждает фактическую подписку Meta или доставку событий.

Webhook GET проверяет verify token, а POST проверяет заголовок
`X-Hub-Signature-256` по HMAC SHA-256 от исходных байтов тела с app secret.
Повторная доставка одного `message.id` не создаёт дубликат. Контакты и сообщения
сохраняются в PostgreSQL миграцией `V122__create_whatsapp_inbox.sql`.

Для будущего автоответчика расширяйте интерфейс `WhatsAppProvider`: входящие сообщения
уже проходят через него и сохраняются отдельно от логики заказов.
