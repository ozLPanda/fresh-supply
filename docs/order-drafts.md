# Незавершённые заказы на устройстве

Формы `/admin/orders/new` и `/admin/orders/barcode` показывают панель
«Незавершённые заказы». Карточки содержат название, покупателя, количество
позиций и сумму; выбранная карточка отмечена «В работе». Можно создать новый
черновик, переключиться на другой, переименовать его или удалить с подтверждением.
Создание нового черновика не очищает предыдущий.

Каждый черновик сохраняет состав и порядок товаров, количества и единицы,
цены, тип продажи, выбранные строки и историю изменения цен, дату заказа,
комментарий, постоянного покупателя и привязку к клиентскому аккаунту.
После обновления страницы восстанавливается выбранный черновик. Для черновика
с другой датой перед оформлением нужно выбрать сегодняшнюю или исходную дату.

Хранение — массив в `localStorage`, ключ
`company_shop_admin_order_draft_v2_<userId>_<mode>`. Пользователи и способы
создания (`selection`, `barcode`) имеют отдельные списки. Это черновики формы
на конкретном устройстве; на сервер они отправляются только при оформлении.
Старая версия с одним черновиком и сохранённые формы заявок помощника переносятся
без удаления исходных данных до успешной записи новой версии.

После успешного оформления удаляется только соответствующий черновик;
ошибка оформления оставляет его в списке. Источник заявки помощника и проверка
её уточнений сохраняются отдельно для каждого черновика. Если браузер не может
записать данные, панель показывает предупреждение: переключение работает в
текущей странице, но обновление или закрытие страницы может потерять правки.

При переключении перечитывается актуальная запись, чтобы работа с разными
заказами в нескольких вкладках не восстанавливала старую копию. Ошибки записи
и удаления остаются в очереди текущей страницы: следующее изменение или
«Повторить» повторяет все ожидающие операции. Предупреждение исчезает только
после записи всей очереди.

После оформления карточка заказа получает явный маршрут возврата в форму
создания с оставшимися черновиками. Этот контекст сохраняется при обновлении
карточки. Внутри него сохраняется собственный маршрут возврата формы в исходный
раздел. Используется `navigate` на проверенный внутренний адрес, без движения
по истории браузера; для прямой ссылки на карточку fallback — `/admin/orders`.
Из маршрута формы убирается уже оформленная `assistantSession`, чтобы возврат
не открывал тот же заказ повторно.
