# Релизы fresh-supply

Репозиторий: `ozLPanda/fresh-supply`. Версия берётся из `desktop/package.json`,
тег — `desktop-v<версия>`. Сборка настроена в `.github/workflows/desktop-release.yml`.

## Короткие описания

- По умолчанию описание Release — одна короткая фраза на русском о результате
  изменений; максимум две короткие фразы, если это необходимо.
- Примеры: «Исправления критических ошибок», «Исправлены ошибки загрузки данных»,
  «Добавлен перенос данных с сайта». Выбирай описание по фактическим изменениям;
  не называй ошибки критическими без оснований.
- Не добавляй разделы, длинные списки функций, инструкции установки, архитектуру,
  перечни тестов и технический отчёт. Подробности остаются в документации проекта.
- Существенное ограничение, необходимое пользователю выпуска, укажи одной
  дополнительной короткой фразой. Подробное описание пиши только по просьбе пользователя.
- После публикации отвечай кратко: версия и ссылка на Release; ссылки на
  установщики добавляй только при необходимости. Не повторяй описание и процесс сборки.

## Публикация

Создавай или публикуй Release по запросу пользователя; вопрос о том, как устроены
релизы, сам по себе не запускает публикацию. Проверь существующий тег и Release,
версию и соответствие установщиков, чтобы не создавать дубликаты. Загрузи файлы
и проверь контрольные суммы до публикации. Для стабильного выпуска, доступного
проверке обновлений приложения, нужны Latest и отсутствие отметки pre-release.
